ABOUT ISSUEFLOW

Built for focused engineering work.

IssueFlow is a fully interactive, browser-based issue tracker built with vanilla JavaScript. It demonstrates workflow management, search and filtering, persistence, accessible dialogs, and tested application logic.

How your data works

Issues are stored in this browser's local storage. Changes persist across reloads here, but they do not sync across devices or accounts. Use Export backup to save a JSON copy, then Import backup on another browser.

Keyboard shortcuts

N Create a new issue when you are not typing in a field.

Privacy

No backend or analytics tracker is installed. Avoid putting confidential information into a public/shared computer.
