ABOUT ISSUEFLOW

Built for focused engineering work.

IssueFlow is a fully interactive, browser-based issue tracker built with vanilla JavaScript. It demonstrates workflow management, search and filtering, persistence, accessible dialogs, and tested application logic.

How your data works

In guest demo mode issues are saved locally in this browser. With GitHub sign-in (when the database is connected), issues are stored in a private, shared Supabase workspace and refreshed across devices. Invite codes let teammates join the same workspace. Cloud edits require an internet connection; guest changes do not automatically migrate.

Keyboard shortcuts

N Create a new issue when you are not typing in a field.

Privacy

Do not add passwords, confidential company information, or personal secrets to demo tasks. Cloud workspaces use database row-level access policies; invite codes should only be shared with trusted teammates.
